# 体調の隠れ相関発見ノート

1日10秒のゆるい記録から、不調と生活要因の「隠れた関連」を自動で見つけ、生活言語の仮説として控えめに提示する個人用ツールです。

## 医療免責（必読）

> **本ツールは医療機器でも診断ツールでもなく、医療の代替にはなりません。**
> 気になる症状は、専門家（医師・医療機関）にご相談ください。
> 記録が負担に感じたら、いつでも中断してかまいません。

## 特徴

| 観点 | 一般的な体調記録アプリ | 本ツール |
|---|---|---|
| 分析軸 | 気圧・天候など固定 | ユーザー定義の任意要因を横断 |
| 時間関係 | 当日のみ | 前日ラグまで考慮 |
| 出力 | グラフ・レポート | 生活言語の仮説文 |
| データ | クラウド前提が多い | ローカル完結を既定 |

## 安全設計

本ツールは、記録・モニタリング自体が症状を悪化させうる「ノセボ効果」などのリスクを考慮して設計されています。

- **SAFE-1**: 1日1回・10秒、項目数上限6
- **SAFE-2**: 達成煽り・連続記録バッジなし
- **SAFE-3**: すべての仮説に「原因とは限らない」を必ず併記
- **SAFE-4**: 「除去」「制限」を強く勧めない
- **SAFE-5**: 医療の代替でない旨をオンボーディングで明示
- **SAFE-6**: 一時停止・全削除をいつでも簡単に実行可能
- **SAFE-7**: 症状が続く場合の穏やかな専門家相談促し

貢献者にもこの安全配慮の遵守を求めます（[SPEC_PlanC.md](SPEC_PlanC.md) 3章参照）。

## セットアップ（ローカル）

```bash
pip install -r requirements.txt
python run.py
# → http://localhost:8000 をブラウザで開く
```

## セットアップ（Railway クラウド）

1. このリポジトリを Railway にインポート
2. 以下の環境変数を設定：

| 変数名 | 説明 | 例 |
|---|---|---|
| `AUTH_USERNAME` | ログインユーザー名（省略時 `admin`） | `admin` |
| `AUTH_PASSWORD` | ログインパスワード（**必ず設定**） | `your-password` |
| `DATABASE_PATH` | SQLite ファイルパス | `/data/health.db` |

3. Volume を `/data` にマウント（SQLite データ永続化のため必須）

## 技術スタック

- Python 3.10+ / FastAPI / SQLite
- PWA（スマホブラウザ対応、ホーム画面追加可）
- 相関分析: Cohen's d / Lift / Spearman（機械学習は使用しない）
